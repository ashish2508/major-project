# Execution status

Updated 11 November 2026. The local academic demo has been verified under D007 and D008. Final submission is due 16 November.

- **Demo.** Follow the [run instructions](../README.md) and use one of the [synthetic pairs](../demo/README.md) or the built-in example. The production app shows the submitted and source passages, highlights their spans, and displays scores. It searches the supplied sources.
- **Verification.** Prettier, TypeScript, ESLint, all 37 tests including native MiniLM inference, and the Next.js production build passed on Windows with Bun 1.3.14 and Node.js 24.18. The production HTTP smoke test loaded the page and readiness route, scored an exact text match with TF-IDF and hybrid, extracted the bundled PDF and matched it with MiniLM, and rejected an invalid PDF and a cross-origin request. Each positive fixture scored 1.000. These are functional checks.
- **Benchmark.** The recorded Linux run completed on 10 November. The validator reproduced 49,621 external annotations. The bounded family-disjoint split used 80/48/48 training, validation and test queries. The held-out set used 36 sources and 57 annotations. TF-IDF and hybrid reached 0.6033 PlagDet. MiniLM reached 0.3047. Validation selected a lexical weight of 1.0, so the hybrid and TF-IDF matched. Recalculation from all saved held-out predictions reproduced the archived metrics exactly. The local model and vocabulary hashes also matched the recorded experiment.
- **Research records.** The [methodology](methodology.md), [benchmark summary](../reports/implementation/benchmark-summary.md), and [article draft](article.md) describe the subset, measured results and limitations. The test set includes one simulated case and uses book text. It gives no direct estimate for Computer Science papers.

The updated build passed 39 tests and the native Windows DirectML smoke check. All nine controlled method/pair requests ran. All three methods recovered the direct copies and produced no negative-control alerts. The semantic reranking retrieved annotated paraphrase candidates, but the highest measured score was 0.5265146731 on CPU and 0.5265148047 on DirectML, below the frozen 0.60 MiniLM threshold. CPU and DirectML made identical controlled-demo decisions, so the limitation is attributed to the fixed model/example combination rather than provider variance. The [milestone report](../reports/implementation/alignment-and-directml.md) records the measurements and verification evidence.

The paragraph-window follow-up completed on 10 November is retained as a descriptive experiment under [paragraph-experiment](../reports/implementation/paragraph-experiment/). On its held-out split, paragraph windows measured PlagDet of 0.3179 for lexical, 0.3140 for MiniLM and 0.3370 for hybrid; these results use a changed windowing/postprocessing configuration and do not replace the frozen PAN comparison above.
